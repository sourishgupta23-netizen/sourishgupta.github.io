Maze Solver Robot

An autonomous robot that navigates mazes using an ultrasonic sensor and servo motor for obstacle detection. Built on a two-wheel chassis with Arduino as the brain, it uses distance-based logic for real-time directional decision-making.

Image: Two-wheel chassis with HC-SR04 ultrasonic sensor
ESP32 IoT HC-SR04
Smart Dustbin Monitoring System

An IoT-based waste management prototype using ESP32 and an ultrasonic sensor to detect bin fill levels (EMPTY/HALF/FULL) in real time. Creates its own WiFi hotspot and hosts a live dashboard at 192.168.4.1 — no internet or app needed. Built for under ₹900.

Tools: ESP32, HC-SR04, Arduino IDE, Breadboard
